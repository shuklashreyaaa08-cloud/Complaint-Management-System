# Complaint Management System

A web-based Complaint Management System developed using Python Flask, HTML, CSS, and SQLite. This application helps users submit complaints and manage complaint records through a simple web interface.

## 🚀 Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework
- **HTML5** – Frontend structure
- **CSS3** – Styling and design
- **SQLite** – Database management

## ✨ Key Features

- User registration and login
- Complaint submission
- Complaint management
- Complaint status tracking
- Database integration

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/shuklashreyaaa08-cloud/Complaint-Management-System.git
```

2. Open the project folder:

```bash
cd Complaint-Management-System
```

3. Install Flask:

```bash
pip install flask
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 🎯 Project Objective

The main objective of this project is to provide a simple platform for submitting, managing, and tracking complaints digitally.
